# AgentLens Replay — Product Hunt launch draft

## Product details

- Primary URL: https://github.com/fang520huang-lgtm/AgentLens
- Product name: AgentLens Replay
- Tagline: Replay Codex runs and find where two attempts diverged
- Description: AgentLens records a Codex run locally: likely file views, commands and output, code changes, and tokens. Explore the interactive timeline, compare two runs to spot the first captured divergence, then export a redacted, single-file HTML report for a PR.
- Pricing: Free
- Status: Available now
- Topics: Developer Tools, Open Source, Artificial Intelligence
- Maker: the repository owner, using a personal Product Hunt account
